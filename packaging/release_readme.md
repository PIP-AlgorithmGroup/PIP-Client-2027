# PIP-Client v0.3.0-alpha.1

本包为预览版，用于本地与队内测试。已接入欢迎页、RMUL 设置与自检工作区、MQTT、UDP HEVC 图传、
控制器串口、原生键鼠输入和诊断；RMUC 比赛页与比赛字段 UI 尚未完成。
真实裁判系统联调与完整硬件矩阵仍未验收。

Windows 解压后运行 `bin/PIPClient.exe`，或使用 Setup 安装；不需要安装 Qt 或开发工具。
Ubuntu 使用 `sudo apt install ./PIPClient-0.3.0-alpha.1-Ubuntu-amd64.deb`，
从应用菜单或执行 `pip-client` 启动。DEB 的依赖由 apt 安装；显卡驱动由系统提供。

进入 RMUL 后按 Esc 打开设置与自检，各项目可自由切换；图传默认停止，需手动开启。
UDP 默认端口为 3334；监听地址须匹配实际网卡。键鼠输出每场默认关闭，启用并完成操作检查后才能确认可用。
完整 ANSI 104 键盘可在窄窗横向查看，悬停时纵向滚轮仍滚动页面。
本场曾有自检通过后，返回欢迎页需二次确认；确认后再次进入需重新建立链路并自检。
串口设置可接入自定义控制器，默认 921600/8N1/无流控，有效 0x0311 数据转发为 MQTT。
设置与自检期间仅本地解析，不转发控制；数据段最多 60 字节、完整帧最多 69 字节。
调试发送/解码工具随源码的tools目录提供，需Python/Tk及requirements_serial.txt中的依赖。
首次访问局域网时按系统提示允许应用访问所需网络。软件不自动更改系统防火墙或驱动。

配置和日志保存在当前用户的数据目录，升级与卸载不主动清除。
本版 D3D11/OpenGL 使用独立视频呈交线程，GUI 忙时保留 HUD 并继续显示最新视频；
正常路径由 GPU 转色，支持能力不足时明确回退。网卡/串口枚举和会话连接保存后台执行。
GUI 仍承担状态协调、部分设置保存及启停等待，界面交互不保证完全无阻塞。

日志入口：欢迎页诊断 / Esc 运行诊断。反馈时附版本、系统、设备与对应会话日志；
分享日志或崩溃转储前检查其中的设备、网络及进程内存信息。

Windows 包未代码签名。Linux 包须以发行说明列出的实测范围为准；
测试通过不代表所有显卡、显示环境或持续运行性能已经验收。
