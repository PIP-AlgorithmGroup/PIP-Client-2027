## 外网下载边界

Windows 通过真实公开 GitHub API 查询 v0.4.0-rc.1，下载约 47 MB Setup 并验证大小和
API sha256 摘要；未执行下载的安装器，未替换用户已有客户端。

Ubuntu 两次真实测试均成功查到版本，访问 github.com 附件时超时；最小 Qt 请求
在尚未收到 HTTP 状态时返回 TimeoutError，HTTP/1.1 与默认请求均复现。
curl 曾成功请求附件，但显式关闭默认配置后的直连也出现连接超时，
不能据此把问题归因于应用或认定外网通路稳定。未更改系统 DNS、代理、TLS 校验或用户网络配置。
Linux 完整外网附件下载尚未验收；断网/超时按错误显示，不误报最新版，允许重试与打开发行页面。
