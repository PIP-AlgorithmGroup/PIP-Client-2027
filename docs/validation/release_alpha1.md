# v0.1.0-alpha.1 发行验收

本记录区分代码回归、部署短测与尚未完成的硬件验收。最终附件的 SHA-256、
冻结提交和最终包复核结果随发行页提供；候选构建日志不代表最终包的提交身份。

## 构建与回归

两平台均使用 RelWithDebInfo、Qt / Qt MQTT 6.12.0、Protobuf 3.20.3 和 FFmpeg 7.1。

| 项目 | Windows 11 x64 | Ubuntu 22.04 amd64（WSL2） |
| --- | --- | --- |
| 完整客户端构建 | 通过，MinGW GCC 13.1 | 通过，GCC 11 |
| QML 静态检查 | 通过 | 通过 |
| CTest | 15/15，116.06 秒 | 14/14，92.75 秒 |
| DEB 脚本行为测试 | 2 项通过，dpkg 专项跳过 | 3/3 通过 |

Linux 发行用 FFmpeg 启用通用 x86 汇编和运行时 CPU 探测，未使用本机专有指令集编译。
启用 HEVC、VAAPI/DRM；本轮未编入 CUDA。VAAPI 编入能力不代表实际硬件输出通过。
发行所用依赖的源码、上游构建选项、SBOM 和许可证随附件提供。

## Windows 安装与运行

候选安装器已经验证当前用户安装、同版本覆盖升级、卸载、卸载注册项和用户文件保留。
两份实际设置文件在测试前后字节一致，额外用户文件和设置目录哨兵均保留。
仅关闭测试创建的客户端进程，不停止已有客户端或 IDE。

部署目录和安装后的程序均在不含 Qt、MinGW 或 FFmpeg 开发目录的 PATH 中启动，
检查完整版本、Qt 版本、界面初始化、至少三次运行快照、无警告及正常关闭返回值 0。
最终 ZIP 与安装器必须从同一剥离调试信息后的部署目录生成，并再次核对冻结提交。
匹配符号、未剥离主程序、提交及二进制校验值保留于本地符号归档。

本机 NVIDIA GeForce RTX 4070 Laptop GPU 的 D3D11VA HEVC 真实输出和 CPU 路径
分别通过原生 Direct3D 11 / UDP 专项短测，各 3 项通过。该测试约 4 秒，
不能作为长稳、全部设备 60 FPS 或 low 帧性能达标的证明。

## Ubuntu 部署范围

部署包含 XCB、Wayland、offscreen 三个插件及 Qt/QML 私有运行库。
三种插件在隔离配置及数据目录、系统 PATH、软件绘制下均完成界面初始化和至少三次快照，
每个进程运行约 8 秒后由测试发送 SIGTERM；这不等同于用户正常关闭验证。
XCB / Wayland 的显示服务器是 WSLg，不等同于原生 Ubuntu 桌面或 GPU 验收。

验证环境通过下载解包的 Ubuntu 包补充系统缺少的 libxcb-cursor 和 VAAPI 库，
不安装系统包、不修改系统 dpkg 数据库。DEB 通过 Depends 交由 apt 解析这些系统依赖；
不私带 libva/libdrm，也不打包厂商驱动。最终 DEB 另行解包检查元数据、桌面入口、
动态库闭包、apt 模拟解析及程序启动，结果见发行附件。

WSL 暴露的 render 节点没有可用 VA display，设备枚举会明确记录 FFmpeg 探测错误；
三种显示插件的启动检查均保留该记录，不能将其记作 Linux 硬解通过。
未发现其他启动错误。测试使用 C.UTF-8；最小环境遗漏 locale 时 Qt 曾发出编码回退提示，
补充明确 UTF-8 locale 后该提示消失。

- 真裁判系统服务器、赛场 RJ45 网络和比赛身份隔离。
- 安装包数字签名、自动更新及跨版本配置迁移；当前仅覆盖同版本重装升级。
