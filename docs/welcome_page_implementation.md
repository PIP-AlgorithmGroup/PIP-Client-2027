# 欢迎页实现与验证

## 当前行为

窗口启动后读取本地偏好；加载过程显示真实状态，无固定延迟、假进度或启动联网。
首次没有默认赛事，选择 RMUL 高校联盟赛或 RMUC 超级对抗赛后才能进入。
RMUL 进入后自动监听已保存的 UDP 图传配置；RMUC 保留本地占位页。均不发送控制指令或启动 MQTT。
RMUL 只有等比视频，Esc 打开基本配置并可返回欢迎页，详见[图传接收](video_receiver.md)。
业务 topic、字段、比赛工作台、HUD、地图与机器人身份继续留空。

设置包含 UI 小/中/大三档、背景轻动效和全屏；诊断显示系统、Qt、窗口平台、实际可取得的渲染状态与通用链路状态。
视频已接入 RMUL 软件解码；3D、GPU/NPU 推理仍未接入/未检查，不将设备存在当成能力验证。
帮助包含键盘说明及用户主动打开的官方资料链接；关于包含背景来源及字体许可。

Tab / Shift+Tab 移动焦点，左右键切换赛事，Space 选择，Enter 激活按钮。
F11 切换全屏；欢迎页 Esc 优先关闭工具面板，再退出全屏；RMUL 中 Esc 打开/关闭图传设置。
面板关闭和返回时恢复可见控件焦点。
右侧工具使用 Lucide 线性 SVG 图标：设置滑杆、诊断波形、帮助问号、关于信息。
按钮不显示中文，悬停/键盘聚焦显示名称提示，保留可访问名称；资源随包离线加载。

## 状态与持久化

`AppController` 由主程序持有，在 GUI 线程使用；QML engine 先于控制器和数据链路销毁。
控制器不持有 DataPipeline。进入请求只排队一次，返回会取消尚未执行的导航回调。

偏好使用 `QStandardPaths::AppConfigLocation/preferences.ini`，通过 QSettings 原子同步，
不依赖工作目录。测试显式传入临时文件路径，不读写用户偏好。

| 键 | 类型与默认值 | 范围与语义 |
| --- | --- | --- |
| version | 整数文本 1 | 仅版本 1 可读取 |
| mode | 字符串，默认空 | 空 / RMUL / RMUC；恢复选择后不自动进入 |
| motion | 布尔文本 false | 只接受 true / false；实际动效还受窗口状态约束 |
| fullscreen | 布尔文本 false | 窗口 / 全屏偏好 |
| ui_size | 字符串 medium | small / medium / large，对应 90% / 100% / 110%；旧配置缺省为中档 |

所有已知值验证通过后一次性应用，未知键不使用。损坏或未来版本配置进入 error，
首次保持默认值，重试失败保留上次完整应用值。可重试或清空偏好恢复默认。
写入失败显示原因，模式和开关保持原来已应用的值。

字体和控件尺寸只受 UI 档位控制，使用逻辑像素；系统 DPI 仍按 Qt 正常映射到物理像素。
赛事选择和进入按钮锚定左下角，工具图标锚定右下角；同一档位下距窗口底边、侧边的边距固定，
窗口变大只增加中间留白。空间不足时只滚动上方品牌区或面板，不偷偷缩小 UI，也不移动底部操作组。
切换赛事、动效或 UI 档位不发出全屏通知，不改窗口尺寸与最大化状态。
全屏通过明确事件切换，退出时恢复进入前的普通窗口或最大化状态；不会因为通用偏好变化重设窗口。

## 资源与渲染

背景使用用户确认的 RoboMaster 2026 全国赛官方纯净版。原图保存在 docs/design；
运行资源为 3840 × 2160 JPEG 和 1280 × 720 海报，来源及处理说明位于
`resources/welcome/notice.txt`，随应用打包。礼包限制为战队宣传、非商业使用，品牌不得变形变色。
该素材不称作 2027 官方主视觉。

标题打包 Barlow Bold / Medium；中文与正文打包 Noto Sans SC 可变字体，均为 OFL 1.1。
应用在创建 QML engine 前注册并设置全局无衬线字体，字体资源加载失败会明确停止启动，
不依赖两平台默认中文回退。完整字体保留，避免仅覆盖当前文案的子集导致后续中文缺字。
图标为 Lucide SVG，采用 ISC / MIT 许可，仅将 currentColor 固定为浅色，未改图形；Qt SVG 负责渲染。
标题使用 TextMetrics 的可见字形边界，避免字体行框上沿留白造成错位。
Qt Quick 原生图片、渐变和缩放可用于两平台，不依赖视频、3D 或厂商 SDK。
背景按窗口物理宽度分档解码（1920 / 2560 / 3840），避免拖动窗口时逐像素重解码。
背景失败使用海报，两图均失败使用明亮纯色；导航不等待图片加载成功。

动效默认关闭；开启后 12 秒循环缩放 3%，只变换背景，文字、按钮与局部遮罩保持稳定。
设置面板内立即预览，关闭面板后继续；窗口非活跃、最小化、隐藏、图片不可用或进入
赛事容器时停止并复位。背景纹理保留复用，在窗口销毁时释放。

## 验证记录（2026-11-11）

环境：Windows 11，Qt / Qt MQTT 6.9.0，MinGW 13.1，Protobuf 3.20.3。
统一 CMake 构建；C++ 使用项目 clang-format，QML 使用 qmlformat 与 qmllint。

- protocol_2027：协议定义与编码回归。
- data_pipeline：回环 MQTT、解码、重连、停止和 QML 通知。
- app_controller：两模式、重复进入、取消导航、偏好恢复、非法配置与写入失败。
- welcome_ui：真实 Main.qml 离屏创建，鼠标/键盘、面板焦点、设置失败回退、全屏快捷键、
  三档与 1024×640 / 1280×720 / 1920×1080 的九种布局组合、固定字号、最大化/普通窗口切模式、
  全屏状态恢复、中文字形覆盖、SVG 图标加载、背景/海报失败及动效停止；并检查非预期 QML 告警。
  动效还通过实际图片变换值验证设置面板预览、关闭面板后继续、停用后复位，避免只测偏好开关。

GUI 测试显式从当前 Qt kit 定位 offscreen 插件，避免误读构建目录中的旧 windows-only 部署。
Windows 离屏测试从系统字体目录加载中文回退。Qt 对某些系统字体的 FreeType 调试提示不影响测试；
图片缺失测试只允许明确匹配的预期资源错误。

可通过 `PIP_UI_CAPTURE_DIR=<已存在目录>` 运行 welcome_ui_test 输出实际 QML 渲染截图，
并设置 `QT_QUICK_BACKEND=software` 检查软件路径。截图不是设计稿，也不是桌面窗口截图。
常规运行 `ctest --test-dir <构建目录> --output-on-failure`。

已检查欢迎页与设置面板的离屏截图；打包后的 PIPClient.exe 也通过 offscreen 启动检查，
能够加载编译后的 QML 模块。桌面窗口控制未获工具授权，窗口级交互、DPI、多屏和
实际 GPU 路径未完成验收；Ubuntu 环境本轮不可用。未测量启动延迟、内存、功耗或长期运行，
未完成 Intel / NVIDIA / NPU 硬件矩阵。以上项目需在对应环境验证，不能以离屏通过替代。

Windows 本地部署需包含 Qt Quick Controls 2 的 QML 模块和插件，并单独部署匹配 ABI 的 Qt MQTT。
独立安装 MQTT 时，某些 windeployqt 版本仍会在 Qt kit 查找 MQTT；可先对官方
Qt6QuickControls2.dll 使用 `--qmldir <ui目录> --dir <运行目录>` 部署 QML 依赖，
再放入独立 MQTT 安装目录中的 DLL。不得把这些开发机路径或构建产物加入版本控制。
