# 原生键鼠控制与测试

主 RMUL 图传页面、MQTT ready、窗口前台且没有菜单/交互子页时自动捕获。采集线程逐个消费原生事件，
维护全部物理键状态和相对量累计；MQTT 工作线程直接采样，不经 GUI 逐周期发布。
Windows 使用独立隐藏窗口 Raw Input；Ubuntu X11 使用独立 X 连接 XI 2.1（保证 grab 期间 raw 交付）；原生 Wayland 使用
Qt 同一 display、独立 proxy/事件队列及 relative-pointer / pointer-constraints 协议。
Wayland 的未加速量不是设备 HID 原始计数；X11 当前采用 evdev keycode + 8 映射，须在目标桌面确认。

## 操作

- 连接 MQTT 后返回主图传页自动隐藏并约束光标，无需额外点击。
- Esc 打开菜单、切换窗口、离开比赛页、进入其他交互页或断线时撤销捕获；恢复不重放旧运动。
- 已经按住的键必须松开再按才能控制；左右 Shift/Ctrl 独立维护，协议输出时合并。
- 角落 HUD 显示具体键名（例如 `W + A + LShift`）、鼠标键名、捕获状态和实际发送率。
- `Esc → 键鼠设置 / 测试` 可离线观察全部键、五个鼠标按钮、运动/滚轮与回报间隔。
- 锁定测试支持无限相对移动；按 Esc、切换窗口或离开测试页退出。测试状态不发送控制数据，
  从控制页进入时仅允许一次全零释放帧。
- 控制和锁定测试期间隔离 Qt 普通键鼠交互，防止隐藏光标误点按钮；Esc 保留菜单退出通路。
- 灵敏度范围 0.05–10 倍，默认 1；Y 反转默认关闭。设置原子保存至应用配置目录 `input.json`。
- 按当前需求默认 200Hz，另提供 75Hz。75Hz 是官方协议标注；200Hz 属联调配置，
  能减少本地等待但不能保证官方系统接纳或将接收端处理延迟压到 5ms。

## 时间、状态与协议

输入健康心跳上限 25ms，无事件的静止设备仍由采集线程续期。原生焦点轮询最长等待 2ms，
MQTT 空闲资格检查 2ms；200Hz 名义周期 5000µs，最多一个周期相位补偿且帧间至少 4000µs，
75Hz 保持最短间隔 13334µs。晚于整个周期则跳过欠下的周期，不补发历史帧；系统晚唤醒仍可能降低实际频率。
没有补发旧帧或历史控制 FIFO。撤销与本地写入串行校验代次；已经交给 TCP 的字节无法撤回。
连接重建清空运动水位，发送失败不推进水位；灵敏度的小数余量跨周期保留。
网络待写超过 4KiB 断开并撤销控制，不承诺网络或远端执行时效，机器人须有自己的超时保护。

输出复用官方 `KeyboardMouseControl`，QoS0、非 retained。16 位按键为
`W S A D Shift Ctrl Q E R F G Z X C V B`；左、右、中键分别编码。
平台坐标右/下为正，官方 Y 负值向下，因此输出时翻转 Y。
协议称鼠标字段为速度而未规定物理单位；本实现使用每次发布的相对增量，不能据此承诺机器人角速度。
200Hz 下如果下游取最新包而不累计增量，可能损失移动量，必须实机标定并核对裁判转发策略。

测试统计分开显示键盘事件、鼠标原生交付与 MQTT 本地交付：最近 1 秒计数率，
最近 1 秒内最多 256 个正时间间隔的均值/最小/P99/最大及倒数。
同一时刻的批量事件计入计数，不伪造零间隔的无限频率。键盘重复 make 单独计数，长按不当作硬件轮询。
原生事件可能被系统合并或拆分，软件看不到设备未上报的 USB 扫描；这不是硬件 polling rate 测量仪。
GUI 以 33ms 合并读取诊断，HUD 刷新不限制输入或 MQTT 频率。

## 工程入口

`InputState` 是线程安全值存储；`NativeInput` 独占系统资源；`InputPacket` 只在 MQTT 线程使用；
`InputController` 由 `MatchSession` 拥有。QML 调用 `setContext` 传入主图传、交互遮挡与测试页面资格。
新增比赛交互页面必须绑定 `Main.interactionBlocked`，不能仅改变视觉可见性。
原生 surface 销毁前同步停止并 join 采集线程；UI 和 pipeline 必须按既有栈生命周期释放。

Ubuntu 构建需安装 `libx11-dev libxi-dev libwayland-dev`（含 scanner）。协议 XML 已入库，无需构建联网。
手动 `native_input_probe` 只在前台运行、不连接 MQTT；Windows 使用 SendInput 验证适配与多键释放，
注入测试不能证明硬件回报率。自动验证与实机限制见[验证记录](../validation/keyboard_mouse_input.md)。
