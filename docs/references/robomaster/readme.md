## 目录

- `manuals/2027/`：用户指定的五本 2027 手册、2027 通信协议，以及同名规则的另一份本地副本。
- `manuals/2026/`：2026 规则、制作规范、通信协议、选手端和裁判端界面手册。
- `manuals/hardware/`：灯条和相机图传模块说明书。
- `webpages/`：网页链接、用途记录和取得的原始 HTML 响应；动态页面不冒称完整离线网页。
- `materials/`：选定包原素材、提取遮罩、官网阵容图和官方雷达圆桌配图。
- `local_archives/`：大型官方安装包和介绍 PPT，已存入本地项目、按目录规则不纳入 Git。
- [完整清单与 SHA-256](catalog.json)。

## 版本与来源边界

两份标题相同的 2027 RMUC 规则 PDF 字节不同：用户指定原件作为主参考，另一份以 `_alternate` 保存。
本轮只确认它们的哈希不同，没有比较正文差异，也不自动将其中一份判断为更新版本。其他重复副本按哈希去重。

手册保留原始字节，清单记录原文件名；本地文件名统一为小写英文、版本号和日期。
HTML 响应按原始字节保存，目录属性禁止 Git 自动转换换行，确保跨平台检出后哈希一致。
已有本地手册的官方链接多数为定位入口，不能当作已经核对远端原件哈希的证明。

2026 官方 UI、字体公告与贴纸仅作注明年份的参考，不能自动视为 2027/RMUL 的完整规范。
品牌礼包版权说明、[既有视觉来源核查](../../design/rmul/visual_reference_audit.md)和雷达源稿未核实的限制均保留。
这里的资料不被自动嵌入、安装或分发到客户端；下载可读不等于获得任意用途授权。
