# PIP 与图传结合的图标候选

用户进一步要求：标志要体现 PIP 和图传元素。本轮保留白灰橙、深蓝白青两套配色，
让三个字母可直接辨认，并将视频画幅、扫描或叠帧融入图形。
这些是独立候选，尚未替换应用图标。

预览：[六种组合](directions.png)。每格包含两套配色，以及 24/32/48 像素实际输出尺寸。

| 编号 | 方向 | PIP 与图传的结合方式 |
| --- | --- | --- |
| 01 | 画幅字标 | 三个字母作为负形嵌入横向视频画幅 |
| 02 | 扫描字标 | 中间 I 化为扫描条，两侧 P 与画幅上下边界组合 |
| 03 | 双端画面 | 两个 P 的内孔采用横向画幅，右侧内孔加入小画面 |
| 04 | 逐帧传递 | 倾斜字标与分段扫描基线组合 |
| 05 | 取景字标 | 完整 PIP 字标与对角取景边界组合 |
| 06 | 叠帧字标 | 两层视频画面与 PIP 字样组合 |

`mark_*.svg` 是透明背景图稿；`*_light.svg`、`*_dark.svg` 与同名 PNG 是配色候选。
全部字样已经转为矢量路径，不依赖设备安装字体。05/06 的字形来自项目已有 Barlow Bold，
许可与来源见[项目随附 OFL 声明](../../../resources/fonts/ofl_barlow.txt)；其他字形为几何绘制。
图稿与 PNG 使用当前 Qt 6.9 SVG 渲染检查，不涉及运行时依赖或构建配置修改。

文字型图标在 16px 下无法保证三个字母与图传细节同时清晰，当前先评估 24px 以上辨识度。
选定方向后仍需单独处理 16px 光学校正、线宽、负形、重心与平台输出，不能把本轮候选当成定稿。

后续反馈要求去掉 PIP 元素，只体现图传；新方向见
[纯图传图标候选](../video_only_icon_concepts/readme.md)。本目录保留为上一轮设计历史。
