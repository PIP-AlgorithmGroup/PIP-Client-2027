# 控制点动画与联盟赛规则核对

日期：2026-11-23。本文区分官方机制、用户视觉要求和独立演示，不代表正式数据源已接入。
完整规则与常见边界见[RMUL控制区整理](rmul_control_rules.md)，本文主要记录动画表达。

## 官方规则

依据：`docs/references/robomaster/manuals/2027/rmul_rules_v1_0_0_20261015.pdf`，
《RoboMaster 2027机甲大师高校联盟赛比赛规则手册》V1.0.0（20261015），
印刷36页§3.3.4.1、印刷37页§3.3.4.2与§3.3.5.3。已阅读完整页面及相关前后条款。

1. 三处控制区为R高地、B高地、中央，开局全部中立。
2. 每方对每个控制区都有独立的占领进度，范围0至5。到5才建立控制；已建立的控制到0才失去。
   因此进度下降到4、3、2、1时，原方仍控制该点。双方均不控制时才是中立。
3. 仅一方有效激活，且另一方进度为0：激活方每秒增加1。
4. 仅一方有效激活，但另一方进度非0：**先每秒减少对方1点**，不能同时增加自己的进度。
5. 双方同时激活：进度变化暂停，直到只剩一方有效激活。
6. 双方均不激活一个**非中立**控制区：双方进度均每秒减1，最终失去控制回到中立。
   原文没有给出中立点部分进度在无人时自动衰减的规则，本演示不擅自扩展。
7. 机器人未再检测到增益点交互模块卡后，激活状态在2秒后失效；不能离开当帧就判无人。
8. 复活后的虚弱机器人无法激活控制区（印刷35页§3.3.2.2）。

满5的蓝点被红方单独持续激活：蓝5→0需5秒，此后红0→5需5秒，共10秒，
中间明确经过中立；反方向相同。这是有效激活持续且没有争夺/中断时的推导，不是所有夺点一律10秒。
从检测离卡到激活失效的2秒应单独处理，不能与5秒计数混成一个统一动画时长。

上方双方横条应表达**控制度**，与每点0至5进度分开：双方初始各600；
一方每控制一处，对方每秒扣1；机器人战亡，本方扣10（印刷37页§3.3.4.2）。
现有完整HUD的50/100及比例仍是早期视觉夹具，不是按新核对规则计算，不能照搬为产品契约。

## 最新用户要求与画法

最终确认：每个控制点的形状仅由当前已确认控制归属`owner`决定；激活方变化本身不改变形状。
地点字母、占领百分比和己敌身份均不能替代归属字段。后续修改顺序见[设计日志](design_log.md)。

- 蓝方控制固定圆形；红方控制固定菱形；中立固定正方形。按绝对红蓝归属，不依己方身份。
- **进入过渡时保留上一占领方的形状，直到规则确认旧归属失效。** 不做形状插值、旋转或缩放。
- 原点尚中立而蓝/红正在积累进度时，仍保留方形，满5确认新归属后直接切为蓝圆/红菱。
- 原归属的剩余进度沿原有外框从12点方向顺时针显示；减少时反向收回。
  只将该现有框的已完成部分点亮，不在图标外围添加独立进度圆环。
- 内部淡蓝/淡红扇面与边框使用同一个径向裁切、同一进度值；进度0没有阵营填充，满5保留淡色底。
  内部底色透明度19%，边框宽3（96×96演示坐标）；字母始终正立，处于最上层。
- 夺点阶段先收回旧方颜色；旧方到0切灰方框，再以进攻方颜色扫过方框。到5才切为新方固定形状。
- 双方有效激活时边框和底色一起停住；暂停播放、手动拖动与减少动态效果均可复现。
- 无数据不是中立：完整HUD继续使用虚线未知框。没有真实进度来源时不自动按墙钟补5秒动画。

“中立进攻期间保留方框”是按用户前一状态形状不变约束作出的视觉选择；
0至5计数与归属建立/失去阈值属于官方规则，二者不能互相替代。

## 演示覆盖与边界

`control_transition.html`是本地独立动画源稿，未替换完整HUD静态基线；所有数值均为规则演示。
图中B/C/R是地点身份，归属仍可为任意一方。默认4倍速，支持1倍实际规则时长和手动定位。
轨道下方蓝/红数值仅供此动画核对，不决定正式HUD是否显示计数。

| 地点 | 固定场景（秒） |
| --- | --- |
| B | 0–5中立→蓝；5–7双方激活暂停；7–12蓝→中立；12–17中立→红；17离卡、19激活失效；19–24红→中立 |
| C | 0–5蓝→中立；5–10中立→红；10–15红→中立；15–20中立→蓝；20后保持 |
| R | 0–5红→中立；5–10中立→蓝；10–15蓝→中立；15–20中立→红；20后保持 |

为了平滑展示，脚本在已知演示输入下按每秒1点插值小数；不声称协议每20ms发送进度。
正式串口控制区激活/归属有明确字段，但MQTT入口及逐点连续计数来源仍须按项目协议核对，
不能用本机RFID检测或推演结果冒充裁判系统确认的全场实时状态。

复现：先设置已有Playwright和浏览器环境，再运行
`node docs/design/custom_terminal/render_control_transition.cjs <临时帧目录绝对路径>`。
检查覆盖关键0/5边界、争夺暂停、2秒离卡夹具、所有六种归属方向、同框裁切和320px布局。
动画不循环，回放由用户触发；减少动态效果时按整秒更新，无连续扫动。
