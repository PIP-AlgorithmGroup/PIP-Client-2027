# RMUL 正式界面实现

本轮将已确认的[视觉原型](rmul_prototype/README.md)落到正式 Qt Quick 界面。
颜色、圆角和版式是项目方案；官方规范与字体资料的证据边界见[来源审查](rmul_visual_reference_audit.md)。

## 页面与层次

- 无画面时只保留居中的视频缺失图标、中文真实状态、短说明和 Esc 菜单入口。
- 实况继续按原比例居中显示，保留黑边；不叠加 Logo、网格、端点或模式装饰。
- `businessOverlay` 与视频及视频占位同级，使用窗口逻辑坐标，内容仍为空。
- 图传接收、断流、暂停、错误和恢复不销毁或隐藏业务挂载层。
- 未来展示模型的最后有效值、新鲜度和身份隔离契约见[图传接收](../video_receiver.md)。
  本轮没有实现业务字段或展示快照，也未改变 DataPipeline 失联清理和控制门控。

## ESC 菜单

统一使用中性灰、深灰文字与橙色强调；保留会话、图传、显示、诊断四个分区。
会话按接入网络、机器人身份和连接状态分组，网络采用两列；机器人先选红蓝再选兵种，
ID/clientID 只读，切换阵营清除兵种草稿。下拉为单向箭头，保留 Qt 键盘导航。
连接配置、图传可编辑字段与只读协议规格均沿用既有后端行为。

中档菜单最大 1120×740 逻辑像素，720p 为 1120×640，1080p 为 1120×740；
小中大档倍率仍为 0.9/1.0/1.1。窗口只改变布局和可用空间，字号不按窗口缩放。
会话与图传页在小窗口内部滚动，底部动作始终固定；关闭不提交草稿、不停止接收。
字体沿用已打包 Noto Sans SC，SVG 随应用打包，不引入新的运行依赖。

## 本地验证

环境为 Windows 11、Qt 6.9、MinGW 13.1，软件离屏渲染。

- 正式客户端和测试通过 CMake/Ninja 构建。
- 完整 CTest 为 7/7 通过，覆盖协议、MQTT、会话、视频、应用控制和 UI。
- QML 通过 qmlformat 一致性和 qmllint，C++ 通过项目 clang-format，差异通过空白检查。
- 完整 `welcome_ui_test` 文件报告为 60 项通过；故意缺失欢迎页图片的用例只接受预期告警。
- 保留真实 UDP→HEVC→VideoView 等比显示、黑边、停止/恢复、端口冲突等既有回归。
- 新增业务挂载层在首帧、超时、暂停、绑定失败、恢复和窗口变化后的对象/值/坐标保持检查。
- 新增最小窗口三档会话动作不随表单滚动检查。
- 1024×640、1280×720、1920×1080 × 三档，逐项切换四个菜单分区并检查边界。
  按需截图输出到被忽略目录，人工查看待机、会话、图传、显示和诊断布局。

复现截图：设置 `PIP_UI_CAPTURE_DIR` 为已存在的输出目录，以项目配置的 Qt 离屏环境运行
`welcome_ui_test rmulLayoutAcrossWindowsAndUiSizes`。
该用例不依赖截图生成执行边界断言，普通回归不会写入截图。

本轮未验证 Ubuntu、Windows 原生窗口交互、多屏、DPI、Intel/NVIDIA 驱动或实际赛场设备；
未测量 1080p60 长稳性能。改动只使用 Qt Quick/Qt Controls 和打包 SVG，不增加 GPU/NPU 依赖。
