# 01 接收画幅精修

根据对纯图传候选 01 的偏好继续收敛，保留“开放画幅与两道接收信号”的轮廓，
不添加 PIP 字母。用户已选择左侧白灰石墨橙红配色，正式资源位于
`resources/app/variants/receiver`，已替换应用默认图标；深蓝青色保留为设计历史。
本目录保留精修过程与对比预览，生产资源说明见[应用图标](../../../resources/app/readme.md)。

预览：[精修与实际尺寸](refinement.png)。底部为 16px 原稿与专用稿的八倍最近邻放大，
用于查看真实像素分布；上方一行是未经缩放的实际尺寸。

## 图形调整

- 视频画幅内孔调整为 232 × 128 单位，约为 16:9；直线边框保持 48 单位。
- 外信号弧使用 128 / 80 单位外内半径，内信号扇形半径为 48 单位。
  两道信号之间与信号到画框断口均保留至少 32 单位，减少缩小后的粘连。
- 16px 单独使用小尺寸稿：画框加厚至 64 单位，对应两物理像素；关键直边与间隙
  贴合像素网格，并去掉内信号的小凹口。底板扩展至整个画布，保留圆角和透明角。
- 配色、图形数量与方向保持一致；没有渐变、字体、外部链接或运行时依赖。

## 资源与输出

- `mark_receiver.svg` 是透明背景的标准主图稿。
- `receiver_light.svg` / `receiver_dark.svg` 是标准配色稿，供 24px 及以上使用。
- `receiver_light_small.svg` / `receiver_dark_small.svg` 是 16px 光学校正稿。
- `light/` / `dark/` 分别提供 16/24/32/48/64/128/256/512px RGBA PNG，
  以及包含 16/24/32/48/64/128/256px 的 Windows ICO。16px 条目使用专用稿。

PNG 使用项目现有 Qt 6.9 SVG 预览器四倍采样渲染；ICO 复用
`tools/generate_app_icons.py` 的 `write_ico` 容器写入函数，保持同一尺寸表与 PNG 压缩格式。
源 SVG 均使用 512 × 512 viewBox；调整的是图形几何，不依赖系统安装字体。
这些 PNG/SVG 可作为 Ubuntu hicolor 与 Qt 窗口资源的候选，ICO 可作为 Windows 资源候选。

精修阶段验证覆盖 SVG 可解析性、Qt SVG 离屏渲染、PNG 尺寸与透明通道、ICO 全部尺寸与像素一致性、
UTF-8/LF 和差异检查；未修改产品运行时代码，未运行完整产品构建与回归，
也未进行 Windows 桌面或 Ubuntu X11/Wayland 的实际安装显示验收。

后续正式接入的构建、安装与验证结果见[本地诊断与桌面部署](../../diagnostics_and_deployment.md)。
