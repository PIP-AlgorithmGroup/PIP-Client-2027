# RoboMaster 2026 官方贴纸图案的红蓝 UI 适配

此修订版替代此前自行绘制的兵种轮廓。1、3、4 号数字和哨兵炮塔图案，
直接从官方 2026 制作规范手册的贴纸原图提取，不用相似字体替代，不重新设计符号。

## 图标与适用范围

- `standard/`：红蓝各七个，透明底，仅显示阵营色图案，无外框、阴影、发光和装饰。
- `compact/`：红蓝各七个，相同图案置于阵营色圆底，以白色前景增强地图上的可见性。
- `viewBox="0 0 64 64"`，图案等比居中。SVG 全部使用路径，不依赖字体或外部文件。
- 红 `#D63232`、蓝 `#246CCB` 为屏幕方案色；它们不是声明为官方规定的 UI 色号。
- 图案提取精度受官方 PDF 内嵌位图分辨率限制。SVG 路径保留二值化后原图的像素轮廓，
  未自行补画笔画；哨兵按 PDF 页面显示方向修正内嵌图片的 180° 旋转。
- 这是官方贴纸图形的客户端适配，黑白原图仍保留在交付包供核对；
  阵营着色和圆底不声称是官方发布的完整红蓝 UI 图标。
