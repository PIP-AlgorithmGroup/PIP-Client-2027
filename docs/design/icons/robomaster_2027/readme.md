# RoboMaster 红蓝双方兵种图标方案（第五版）

大图标保留机器人造型和编号角标；仅小地图图标中的重装、步兵 3、步兵 4 改为独立大号 1/3/4。
空中、哨兵、飞镖、雷达保留各自的兵种符号。
这是依据赛事素材制作的 UI 适配方案，不是官方发布或认证的整套图标。

## 大图标与小图标

| 对象 | `standard/` 大图标 | `compact/` 小地图图标 |
| --- | --- | --- |
| 重装 1 | 双机械臂机器人造型 + 1 角标 | 官方贴纸数字 1 |
| 步兵 3 | 步兵机器人造型 + 3 角标 | 官方贴纸数字 3 |
| 步兵 4 | 步兵机器人造型 + 4 角标 | 官方贴纸数字 4 |

| 哨兵 | 炮塔符号 | 炮塔符号 |
| 飞镖 | 镖体符号 | 镖体符号 |

`standard/` 与第三版大图标逐文件一致；`compact/` 与第四版小图标逐文件一致。
目录表示用途，不以 PNG 分辨率决定图形：大图标的低分辨率导出仍保留机器人造型。

## 格式与验证

64×64 viewBox，无字体或外部文件依赖。大图透明底，小地图使用阵营色圆底。
红 `#D63232`、蓝 `#246CCB` 是方案屏幕色，不声称为官方指定色值。
28 个 SVG、168 个透明 PNG（24/32/48/64/128/256 px），附深浅背景及实际像素尺寸预览。

已检查大图与第三版逐字节一致、小图与第四版逐字节一致、预览上方大图区域像素一致，
以及 SVG XML、PNG 尺寸与透明度、红蓝几何一致性、UTF-8/LF；已人工查看修正预览。
仅修改图稿，未接入客户端，未执行 Qt 构建和 Windows/Ubuntu 实机显示验证。
