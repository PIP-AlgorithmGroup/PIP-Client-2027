# RoboMaster 红蓝双方兵种图标方案（第四版）

小图标以数字和兵种符号为主体：重装用 1，两台步兵分别用 3/4；空中、哨兵、飞镖、
雷达使用各自的符号。已去掉重装和步兵的完整机器人轮廓及角标，数字直接占据主要显示区域。
这是依据现有赛事素材制作的 UI 方案，不是官方发布或认证的整套图标。

## 界面适配

- `standard/`：透明底、红蓝数字或兵种符号。
- `compact/`：阵营色圆底、白色数字或兵种符号。
- 64×64 viewBox，路径及基础图元，无字体、外部引用、滤镜、阴影、渐变和发光。
- 红 `#D63232`、蓝 `#246CCB` 为本方案屏幕色，不冒称官方指定色值。
- 官方符号做前景提取、去光晕、等比缩放和阵营着色；受原始位图精度限制，轮廓不是原始矢量稿。
- 1/3/4 使用大号独立数字，不叠加机器人或编号角标；已查看 24/32/48/64 px 实际尺寸。
- 保留相同兵种的红蓝几何，避免阵营切换造成识别形状变化。
