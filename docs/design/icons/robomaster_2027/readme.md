# RoboMaster 红蓝双方兵种图标方案（第三版）

本版用兵种图形作为主体，替换前一版的纯编号图标。阵容为重装 1、步兵 3、步兵 4、
空中 6、哨兵 7、飞镖 8、雷达 9。两台步兵共用车辆图形，使用右下角 3/4 辅助区分。
这是依据现有赛事素材制作的 UI 方案，不是官方发布或认证的整套图标。

## 界面适配

- `standard/`：透明底、红蓝兵种图形，重装和步兵保留少量白色结构线。
- `compact/`：阵营色圆底、白色图形，重装和步兵用阵营色结构线。
- 64×64 viewBox，路径及基础图元，无字体、外部引用、滤镜、阴影、渐变和发光。
- 红 `#D63232`、蓝 `#246CCB` 为本方案屏幕色，不冒称官方指定色值。
- 官方符号做前景提取、去光晕、等比缩放和阵营着色；受原始位图精度限制，轮廓不是原始矢量稿。
- 3/4 是辅助编号，24/32 px 下较小。需要准确读号时建议至少 48 px；
  地图若采用更小图标，应由界面同时提供车辆编号文字。
- 保留相同兵种的红蓝几何，避免阵营切换造成识别形状变化。
