# RoboMaster 2027 红蓝兵种图标提案

本方案用于 PIP-Client 自定义终端的阵容、状态栏和小地图。图标遵循所提供的
2027 V1.0.0 手册中的兵种名称、阵营和编号，采用纯色、几何轮廓和显著数字。
它是参照手册视觉语言制作的设计提案，不是官方发布的 UI 素材，也不表示已获得官方视觉验收。

两份参赛手册已检查，没有据此推导额外的兵种或 UI 视觉强制规范。
2027 阵容表没有独立的英雄、工程或 5 号步兵，本方案不沿用往届阵容。

## 设计选择

- `standard/`：14 个图标，红蓝各七个；建议显示尺寸至少 48×48 px。
  上方是兵种功能轮廓，下方是独立编号，外框采用统一切角牌形。
- `compact/`：14 个小地图图标；建议 24～32 px，使用纯色圆底及更大数字。
  与标准版共用编号映射。
- 两台步兵共用轮廓，分别保留 3 和 4；不通过左右翻转、深浅色或细小装饰区分。
- 重装采用宽车体和粗发射管；步兵采用轻车体和单发射管；哨兵采用守卫轮廓和单发射管；
  空中使用旋翼；飞镖使用镖体和尾翼；雷达使用天线符号。
  这些都是功能示意，不规定各队真实机械结构，也不是官方兵种徽记。
- 同一兵种的红蓝图标除阵营颜色和可访问性文字外，所有形状、朝向及比例一致。
- 所有独立 SVG 的编号均为路径，不依赖字体、外部图片或网络。
  图标外部透明，无渐变、阴影、发光、纹理或品牌标识。
- 红色为 `#D63232`，蓝色为 `#246CCB`，前景为白色。这是为屏幕对比选择的方案色值，
  不是官方 UI 色号；制作规范 S80 中 `#FF0000` / `#0000FF` 指空中机器人航行灯目标色，
  不能将其当作整套 UI 的强制色值。
- 编号是兵种编号，不是通信协议完整机器人 ID。空中 6 表示空中系统，
  不用于区分该系统内的四架空中机器人。

## 交付与验证

SVG 源稿采用 `0 0 64 64` 坐标系，`width`、`height` 默认为 64。
PNG 导出提供 24、32、48、64、128、256 px 六档，保留透明通道。
预览包含深浅背景对照及按实际像素显示的尺寸检查页。

已检查 28 个 SVG 的 XML、标题和描述、编号完整性、红蓝轮廓一致性、
步兵轮廓一致性以及无外部依赖；已检查 168 个 PNG 的尺寸、透明通道和边缘留白。
已人工查看深浅背景与实际尺寸渲染。标准版在 24～32 px 时细节有限，
此范围建议采用纯编号版本。

本次只交付设计源稿和导出预览，没有接入客户端，因此没有执行客户端构建或回归测试。
渲染已在 Windows 的 SVG 工具中检查，Ubuntu 与 Qt 实际加载显示尚未验证。
