# 新图形方向探索

用户反馈：前两套图形均不认可，只保留白灰橙、深蓝白青两套配色。
本轮不再微调取景框或 P 字拼接，展开九种独立轮廓供选择。当前软件图标未替换。

预览：[九种方向对比](directions.png)。每格包含单色轮廓、两套配色和实际小尺寸预览。

| 编号 | 方向 | 图形特点 |
| --- | --- | --- |
| 01 | 汇流 | 上下曲面围出一条开放流道 |
| 02 | 引力 | 开放轨道与偏心焦点 |
| 03 | 掠影 | 两片上扬曲面 |
| 04 | 竞锋 | 对称棱线与向心负形 |
| 05 | 棱镜 | 三块切面与中心孔 |
| 06 | 聚光 | 四个曲面汇向中心 |
| 07 | 折流 | 两条宽折带与斜向切口 |
| 08 | 脉冲 | 连续起伏的单笔宽带 |
| 09 | 交织 | 两道折回带面彼此穿入 |

`mark_*.svg` 是透明背景单色图形；`*_light.svg` 与 `*_dark.svg` 是对应配色候选。
当前为方向探索，后续按选择继续调整比例、负形、品牌关联与小尺寸光学表现。
渲染使用当前 Qt 6.9 SVG，未增加运行时依赖；本轮只增加设计资料，不涉及产品构建或部署变更。

后续明确要求体现 PIP 与图传元素，新的六套组合见
[PIP 与图传结合的候选](../pip_concepts/readme.md)。
