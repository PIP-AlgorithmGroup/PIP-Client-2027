# 第二轮图标结构精修候选

这些是待审阅候选，不是最终品牌定稿。第一轮仅提出方向并完成资源尺寸、平台集成，
不足以视为完成设计；当前 `resources/app/variants` 中的图标继续作为临时占位。
本目录单独保存第二轮图形与实际 Qt SVG 渲染预览，尚未替换运行时资源。

| 方向 | 本轮结构变化 | 仍需审阅 |
| --- | --- | --- |
| A / 画面链路 | 将分离的 L 形与播放框整合成连续取景孔；橙色折角成为框架本身 | 更强调图传，对 PIP 字母的关联较弱 |
| B / 互连终端 | 将两个分离部件重组为交错主体，统一粗细、圆角与斜向通道 | 字母识别与抽象链路之间的取舍 |
| C / 竞技信号 | 删除天线帽与房顶结构，改为连续折返、等宽骨架与宽负形 | 目前更接近抽象 S，需要确认是否适合品牌 |

SVG 是独立可编辑图稿。PNG 由当前 Qt 6.9 `QSvgRenderer` 以四倍采样渲染，
16/24/32/48/64 像素用于评估明暗背景下的识别度；256/512 像素用于审阅整体构图。
跨尺寸光学调整、最终配色及正式资源替换仍需在方向确认后完成，不能把补齐尺寸当作定稿。

对比图：[comparison_v2.png](comparison_v2.png)。原稿与本轮稿并排展示，
重点检查轮廓、负形和视觉重心的变化，而不是只比较材质或渐变。

## 第三轮：收敛 A / B

根据用户对 A、B 风格的偏好，后续继续这两个方向，C 保留为历史候选。
本轮只新增设计预览，尚未替换应用图标。

- A 保留瓷白、石墨与橙色取景框，主要边框统一为 56 单位，重做孔洞比例并上移 4 单位平衡视觉重心。
- B 保留深蓝与白青互连，白色部分改为闭合 P 内孔，右上端口间距由 6 扩至 28 单位，减少缩小时的字形误读。

两套候选均通过当前 Qt SVG 渲染与 PNG 尺寸/透明通道检查；16px 的最终像素对齐仍待选定后处理。
第三轮图稿使用 `_v3` 后缀保存，预览见 [comparison_v3.png](comparison_v3.png)。
