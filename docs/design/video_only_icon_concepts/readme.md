# 纯图传图标候选

本轮移除 PIP 字母和字标，图形只表达视频传输。继续比较白灰橙与深蓝白青两套配色。
当前仍为独立候选，尚未替换应用图标。

预览：[六种纯图传方向](directions.png)。每格提供两套配色和 24/32/48 像素实际输出。

| 编号 | 方向 | 主要意象 |
| --- | --- | --- |
| 01 | 接收画幅 | 画面窗口与宽信号弧融合 |
| 02 | 图像接力 | 两层视频画幅通过通道接续 |
| 03 | 扫描帧 | 实时扫描线穿过画面 |
| 04 | 帧片 | 逐级错位的图像帧 |
| 05 | 入画 | 输入帧带进入显示窗口 |
| 06 | 快门传输 | 画面孔与输出方向结合 |

`mark_*.svg` 为透明背景原稿，`*_light.svg` 和 `*_dark.svg` 为带应用底板的配色候选，
同名 PNG 为 512px 预览。图形不含字母或字体依赖，均通过当前 Qt 6.9 SVG 加载与尺寸检查。
信号弧只是传输意象，不表示客户端仅通过无线接入；实际业务链路与接入方式没有改变。

当前先比较轮廓与图传关联，选定方向后再调整负形、重心、16px 像素对齐，
并生成正式 Windows/Linux 资源。候选预览的通过不等于完成原生平台桌面验收。

后续按用户偏好收敛 01“接收画幅”，标准尺寸与 16px 专用稿见
[接收画幅精修](../receiver_icon_refinement/readme.md)。
