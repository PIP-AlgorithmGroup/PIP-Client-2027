# PIP-Client v0.1.0-alpha.1

首个可安装预览版，供队内跨设备测试。版本源、程序显示、日志和安装包统一为 0.1.0-alpha.1。

## 本版功能

- 欢迎页、RMUL / RMUC 模式选择，窗口与 UI 档位独立配置。
- 会话网卡与身份配置，官方 MQTT / Protobuf 双向基础链路及本地接入测试。
- RMUL UDP HEVC 图传、等比显示、解码设备探测与 CPU 回退。
- 图传统计、分阶段延迟、垂直同步设置与独立业务 UI 挂载层。
- 每次启动日志、运行诊断、尽力生成的原生崩溃证据与跨平台应用图标。

## 下载与使用

Windows x64 提供免安装 ZIP 和当前用户安装程序 Setup.exe；均无需安装 Qt 或开发工具。
ZIP 解压运行 `bin/PIPClient.exe`；Setup 提供安装、覆盖升级和卸载。
Ubuntu amd64 提供 DEB，使用 `sudo apt install ./PIPClient-0.1.0-alpha.1-Ubuntu-amd64.deb`，
从应用菜单或运行 `pip-client` 启动。进入 RMUL 按 Esc 配置网络和图传，UDP 默认端口 3334。

安装/升级/卸载不主动清理用户配置和日志。遇到问题通过诊断入口收集对应日志，
反馈时说明版本、操作系统、GPU、驱动、解码方式和复现步骤。
SHA256SUMS 用于核对下载内容；Windows 包暂未签名。

## 已知限制

- 真实裁判系统联调尚未完成；本地测试不能证明赛场网络、身份与官方服务器行为。
- RMUC 页面、比赛业务字段 UI、原始键鼠控制尚未完成。
- 本版不承诺全设备 60 FPS 或硬解性能；Intel 核显、混合显卡、设备丢失恢复和长稳矩阵仍待继续实测。
- Ubuntu 的显示环境和 GPU 验收范围独立记录，不能由 Windows 或离屏测试推定。
- 本版没有自动更新；卸载不会自动删除日志或设置。
