# PIP-Client v0.2.0-alpha.1

本次预发行版将视频呈交从 GUI 事件循环分离，并以 GPU YUV/硬件纹理通路减少像素往返。

- Windows D3D11 和 OpenGL 使用 Qt RenderControl/QRhi 独立呈交线程，GUI 忙时保留 HUD、继续显示新视频。
- 保留 D3D11 硬件共享纹理和 GPU 转色；按实际设备能力回退，不要求 NVIDIA 或独显。
- 网卡健康查询、网卡/串口枚举、会话连接校验和保存后台执行；减少 GUI 系统调用停顿。
- 增加收帧、解码、邮箱、纹理与呈交分段诊断，并区分独立/Qt 原呈交循环。
- 发布前修复呈交错误状态跨线程读取和独立模式诊断标签。

## 验证与边界

产品实测 GUI 阻塞约 250ms 时，三组正式短测仍各呈交 15 个新视频帧，最大间隔约 17–18ms。
此前 Windows Release 恢复前台阶段首包读出到应用呈交平均 1.003ms、P99 2.739ms；
该值不是 GPU 完成或显示器亮屏时间，也不是所有设备的性能承诺。
全阶段 low1≥50fps 的目标仍未全面达到，剩余系统/驱动长尾继续保留在验证报告中。

后端与 QML 已分层，但 GUI 仍承担状态协调、少量配置写盘和启停资源等待，
不能视为所有业务已迁离 GUI。详情见 [GUI/后端检查](../validation/video/gui_backend_separation.md)
和[独立呈交验证](../validation/video/independent_presentation.md)。

Windows/Ubuntu 最终发行构建、测试、安装和冻结提交证据随附件提供。
Intel/AMD 核显、混合显卡、原生 Ubuntu VAAPI、驱动重置和多小时长稳仍未完成实机验收。
Linux WSLg 图形验证不能替代原生 Ubuntu 硬件验证。Qt 固定 6.12.0，使用同版私有 RHI 头文件。
原生 Ubuntu 22.04 的系统库和显卡驱动由 apt/系统提供，不随包私带厂商驱动。

## 下载

Windows x64：Setup.exe 当前用户安装，或 ZIP 解压运行 `bin/PIPClient.exe`。
Ubuntu 22.04 amd64：`sudo apt install ./PIPClient-0.2.0-alpha.1-Ubuntu-amd64.deb`，运行 `pip-client`。
设置和日志在当前用户目录，安装与卸载不主动清理；本版不提供自动更新，Windows 包未签名。
使用过往已验证驱动，不据此声明所有厂商的最低驱动版本。

附件提供源码、依赖源码与来源、构建选项、验证记录及 SHA256SUMS。
含 GPL Qt MQTT 的二进制组合保留 GPL 文本和对应源码；原项目 Apache 声明和各依赖许可证随包提供。
RMUC 比赛 UI、真实裁判系统联调和完整硬件矩阵仍未完成。
