# PIP-Client v0.4.0-rc.1

本版本完成 RMUL HUD 前端与不同比例窗口布局，沿用已有 MQTT、图传、控制器和键鼠链路。
比赛遥测尚未接入 HUD，未接入字段保持未知，不使用演示数据。rc.1 是候选预发布标识，
不代表真实裁判系统、完整硬件矩阵或正式比赛已经验收。

- 双方顶部采用 1/3/7 号卡片，按已保存身份强调本人；没有 4 号步兵、建筑或等级显示。
- 补充计时、控制度、B/C/R 状态、目标详情、双弧热量、准星与快捷键提示，按最新设计使用局部投影。
- 加入 Silver 竖向静态小地图及经济区；未接入遥测时不绘制机器人位置、朝向或射击信息。
- 底部按血量、超电、缓冲与功率、模块状态排列，区分未知状态与真实零值。
- 右上角精简帧率与键鼠诊断横向叠加、上边缘对齐；详细信息保留在 Esc 设置与诊断中。
- 修复全屏和不同比例窗口的边距：顶部、底部与角落按实际窗口吸附，视频及中心战斗区保持比例。
- 同步设计档案、官方图标、地图素材与验证记录。

## 使用与验证边界

进入 RMUL 后图传默认停止，需手动开启；键鼠输出每场默认关闭，启用并完成操作检查后确认可用。
已有用户设置继续保留，升级与卸载不主动清理配置和日志。Windows 安装包未签名。

HUD 合入时两平台 Qt 6.12.0 正式客户端、QML 静态检查与完整 UI 回归通过；
UI 各 131 项通过、0 失败、3 项按后端条件跳过。Windows 原生专项覆盖多档窗口比例、
全屏往返及实际 UDP 视频；未使用实体 16:10 显示器切换，不据此扩展多屏或 DPI 验收结论。
详见 [RMUL 验证](../validation/rmul.md)。最终发行提交、完整构建与 CTest、安装卸载、
解包启动、依赖源码及 SHA-256 结果随发行附件的 validation.md/json 与 SHA256SUMS 提供。

Ubuntu 常规 UI 回归使用 offscreen/software；WSLg 启动不等于原生 Ubuntu 桌面或 GPU 验收。
实体控制器、真实裁判系统与赛场网络、Intel/AMD 与混合显卡、原生 Ubuntu VAAPI、
驱动恢复和长稳仍按既有报告保留未验证范围。
