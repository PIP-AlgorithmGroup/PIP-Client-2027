# PIP-Client v0.3.0-alpha.1

本版本新增完整的 RMUL 设置与赛前自检工作区，配置和检查可自由切换，无需按固定顺序完成。

- 统一准备概览、MQTT、图传、自定义控制器和键鼠检查，保留同场草稿和后台连接。
- 设置面板保留窗口周围留白，按可用空间滚动；完整 ANSI 104 键盘自适应键帽文字，窄窗可横向查看。
- 图传每次进入比赛默认停止，必须手动开启；键鼠“启用输出”仅对本场有效，启动和比赛边界默认关闭。
- 键鼠输出开启且四项实际操作有证据后，才能确认键鼠可用；关闭输出立即撤销确认。
- 自定义控制器可选择不使用；检查期间仅本地解析，不转发控制，退出检查丢弃半帧。
- 本场曾有实际自检通过后，返回欢迎页需二次确认；取消保留准备状态，确认后释放链路、清除自检进度。
- 修复鼠标悬停完整键盘时纵向滚轮无法滚动页面的问题，保留窄窗横向滚动。

## 验证与边界

Windows 与 Ubuntu 使用 Qt 6.12.0，相关构建、QML 静态检查及回归结果见
[RMUL 验证](../validation/rmul.md)和[键鼠验证](../validation/keyboard_mouse_input.md)。
Windows 原生窗口专项覆盖面板布局、完整键盘、实际视频链路和滚轮派发；
Ubuntu 常规 UI 回归使用 offscreen/software，不等于实体桌面、硬件输入或 GPU 后端验收。
实体控制器、官方赛场联调、原生 Ubuntu 桌面、硬解矩阵和长稳仍按既有报告保留未验证范围。

已保存的连接和灵敏度参数继续保留，再次进入需重新建立链路、手动开启输出并自检。
